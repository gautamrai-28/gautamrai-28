## 💼 Projects

### 🤖 [AutoDocs — AI-Powered Repository Documentation Generator](https://autodocs-frontend-eight.vercel.app/) <sub>*(May 2026 – Jun 2026)*</sub>

> A full-stack web application that automates codebase parsing and documentation generation using LLMs.

**Key Features**
- Engineered a full-stack application with a **FastAPI** backend and **React/Vite** frontend to automate codebase parsing and documentation generation
- Integrated the **Groq API** (LLMs) to perform multi-tier code analysis — generating READMEs, module summaries, and function-level explanations
- Designed an **asynchronous pipeline** with thread-safe job management and background workers to prevent memory leaks and optimize cloud resources
- Implemented **predictive repository scanning** to manage API usage within strict TPM/RPM quotas and mitigate rate-limiting
- Deployed a secure **CORS-enabled** client-server architecture across **Vercel** and **Render** with environment-driven **CI/CD** configuration

**Tech Stack:** `FastAPI` `React` `Vite` `Groq API` `CORS` `Vercel` `Render` `CI/CD`

**Highlights:** Solved real-world LLM rate-limiting constraints through predictive scanning and a thread-safe async job pipeline — a practical lesson in designing around third-party API quotas at scale.

### 🖥️ [CPU Scheduler Visualizer — Full Stack Web Application](https://cpu-scheduler-visualizer-ny42.onrender.com/) <sub>*(Dec 2025 – Jan 2026)*</sub>

> An interactive visualizer for core operating system CPU scheduling algorithms with real-time animations.

**Key Features**
- Developed a CPU Scheduling Visualizer using **C++** for core algorithm logic, integrated with a **Node.js** server to bridge backend computation with frontend visualization via **REST-style** endpoints
- Implemented major **operating system scheduling algorithms** and visualized process execution timelines with dynamic, real-time animations
- Implemented a seamless data pipeline using **JSON** to exchange real-time scheduling data between the C++ backend and frontend
- Deployed the application on **Render** with version control and collaborative workflow managed via **Git** and **GitHub**

**Tech Stack:** `C++` `Node.js` `REST API` `JSON` `Render` `Git` `GitHub`

**Highlights:** Bridged low-level algorithmic C++ logic with a modern web frontend, translating classic OS scheduling theory into an interactive, real-time visual tool.
